## Funcionalidades

- Inicio de sesión con validación de credenciales.
- Mensaje de error cuando las credenciales son incorrectas.
- Panel de control con información del usuario.
- Ruta protegida para impedir el acceso sin iniciar sesión.
- Cierre de sesión.
- Diseño responsivo para computadoras y dispositivos móviles.

## Escenarios de prueba

1. Ingresar credenciales incorrectas y comprobar el mensaje de error.
2. Ingresar credenciales correctas y comprobar el acceso al panel.
3. Intentar acceder al panel sin una sesión iniciada y comprobar la redirección al login.
4. Cerrar sesión y comprobar que se regresa al login.
